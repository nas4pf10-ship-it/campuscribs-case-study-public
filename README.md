## Publish with GitHub Pages

This repository contains a static, dependency-free HTML page. To publish it:

1. Open the repository's **Settings**.
2. Select **Pages** in the left navigation.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for the Pages deployment to complete. GitHub will display the published URL in the Pages settings.

The expected project-site URL is:

https://nas4pf10-ship-it.github.io/campuscribs-case-study-public/

The URL becomes usable only after GitHub Pages is enabled and the deployment succeeds.

## Scope and privacy
